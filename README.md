## 🌟 نظرة عامة على المنصة الكاملة (Fullstack Architecture)
تم تطوير وتحديث هذه المنصة لتكون **منصة ويب متكاملة (Real Fullstack Platform)** مبنية وفق أعلى المعايير الهندسية والمهنية لتشغيل وإدارة **برنامج إعداد وتأهيل الماستر كوتش (الإصدار 3.0 - النسخة التطويرية 2026)**، والمستندة إلى وثيقة الحقيبة التدريبية لشركة **تمكين الرؤية للاستشارات المهنية** (`cyce52.com`).

تجمع المنصة بين:
1. **خادم خلفي متين (Express 5 + SQLite WAL + JWT + Multer)** لتأمين البيانات وحفظ الملفات وإدارة الصلاحيات.
2. **واجهة مستخدم تفاعلية متقدمة (Responsive RTL Executive UI)** تتوافق تماماً مع الهوية البصرية لشركة تمكين الرؤية (كحلي ملكي `#0B132B`، زمردي `#059669`، ذهبي `#D97706`).
3. **نظام التقدم المزدوج المستقل (The Dual-Progress Engine):** الفصل الصارم بين استيفاء المتطلبات الكمية والساعات (240 ساعة)، ومسار تحقق الكفايات الـ 44 والروبركات الستة.
4. **لوحة تحكم إشرافية عليا للمشرف العام الماستر كوتش عبدالكريم الخليفي (Admin Dashboard):** لمراجعة وتقييم مهام الكوتشز، رصد الملاحظات والتسجيلات الصوتية، إدارة البوابة الأخلاقية، وإصدار قرارات ومحاضر التخرج والاعتماد الرسمية.

## 🏛️ المكونات البرمجية والوظيفية للمنصة

### 1. نظام المصادقة والتحكم بالوصول (Authentication & RBAC)
* توليد توكنات JWT مشفرة وتخزينها في جلسة المتصفح.
* حماية مسارات API عبر وسيط `requireRole('admin')` و `requireRole('coach')`.
* إمكانية تسجيل كوتش متدرب جديد برقم قيد معتمد تلقائي (`MC-2026-XXX`).

### 2. محرك رفع الأدلة الثبوتية الحقيقي (Multipart File Upload Engine)
* معالجة الملفات عبر وسيط `multer` مع التخزين المحلي في مجلد `uploads/`.
* التحقق التلقائي من نوع الملف (PDF, DOCX, MP3, WAV, PNG, JPG) بحد أقصى 50 ميجابايت للملف.
* تسمية فريدة للملفات مع منع التضارب وتوثيق وقت الإيداع وحجم الملف ونزاهة نزع الهوية.
* رفع تلقائي لإصدار المهمة في قاعدة البيانات (مثل `v2.0` إلى `v2.1`).

### 3. استمارة التأمل المهني الرباعية المعتمدة (4-Part Reflection Store)
حفظ واسترجاع أقسام التأمل الأربعة المعتمدة بلائحة الحقيبة:
1. **ماذا فعلت تحديداً؟** (الإجراء والموقف المهني)
2. **لماذا؟** (الأسس النظرية والنماذج التفسيرية المعتمدة)
3. **ما أثره الملحوظ على المستفيد؟** (الأثر السلوكي والنتائج)
4. **ما الذي سأغيره أو أطوره مستقبلاً؟** (خطة النمو المهني المستمر)

### 4. لوحة تحكم الماستر كوتش عبدالكريم (Master Coach Admin Dashboard)
* **المؤشرات الحيوية (KPIs):** إجمالي الكوتشز المسجلين، المهام المسلّمة بانتظار التقييم، الكوتشز المعتمدين للتخرج، ونسبة الامتثال للبوابة الأخلاقية.
* **جدول إدارة الكوتشز المتدربين:** استعراض جميع المتدربين مع نسبة إنجاز الساعات، نسبة الكفايات، عدد المهام المنجزة، والتبديل الفوري بين ملفاتهم لمتابعتها مباشرة.
* **طابور مراجعة المهام الفوري (Review Queue):** مراجعة الأدلة المرفوعة، رصد الدرجات من 5.00، كتابة الملاحظات الإشرافية، إرفاق رابط التسجيل الصوتي الإشرافي، واعتماد المهمة أو طلب تعديلها.
* **إصدار شهادات وقرارات التخرج:** تدقيق آلي للضوابط السبعة وإصدار المحضر الرسمي الصادر برقم اعتماد فريد ومختوم رقمياً.
* **إعادة ضبط وتصدير البيانات:** إعادة تعيين بيانات العرض التوضيحي، وتصدير قاعدة البيانات كنسخة احتياطية JSON.

### 5. محرك منع تكرار المستفيد داخل الأداة الواحدة (Anti-Duplication Engine)
* التزاماً صريحاً بلائحة الحقيبة (ص10، ص30): يُمنع منعاً باتاً تكرار رمز المستفيد داخل عداد الأداة الواحدة (MBTI, Wheel of Life, SWOT).
* فحص مزدوج على مستوى الخادم (Server-side 400 validation) وعلى مستوى واجهة المتصفح، مع إظهار نافذة إرشادية وتفسير نظامي عند محاولة التكرار، مع السماح النظامي للمستفيد نفسه بالاستفادة من أدوات مختلفة أخرى.

### 6. مصفوفة الروبركات الستة ومحرك الحظر الأخلاقي الحاسم (Critical Blocker)
* 6 روبركات رسمية تغطي: (1) الجلسات المهنية، (2) ملف الإنجاز الشامل، (3) الورقة العلمية، (4) المشروع الابتكاري، (5) المقابلة الختامية، (6) الإشراف المهني.
* احتساب المتوسط المرجح بدقة من 5.00.
* **قاعدة الحظر الأخلاقي الحاسم:** الإخفاق في أي معيار حرج (أقل من 3/5 في معايير الأخلاقيات أو حماية الخصوصية أو السلامة النفسية) يؤدي فوراً إلى تفعيل الحظر وحجب توصية التخرج وإلغاء إمكانية إصدار القرار مهما كان المتوسط الحسابي العام مرتفعاً.

### 7. بوابة السلامة الأخلاقية وسجل الإحالات التخصصية
* 7 نقاط تدقيق أخلاقية إلزامية مستقلة.
* سجل رسمي للإحالات الطبية والنفسية لإثبات الالتزام بحدود الممارسة المهنية ونطاق الكوتشنج.

## 🔌 واجهات برمجة التطبيقات (RESTful API Documentation)

### 1. المصادقة والحسابات (`/api/auth`)
* `POST /api/auth/login` - تسجيل الدخول والحصول على JWT Token وبيانات المستخدم.
* `GET /api/auth/me` - التحقق من الجلسة الحالية وبيانات الكوتش المسجل.
* `POST /api/auth/register` - تسجيل كوتش متدرب جديد برقم قيد رسمي.
* `POST /api/auth/logout` - إنهاء الجلسة.

### 2. الكوتشز وملفات الإنجاز (`/api/coaches`)
* `GET /api/coaches` - استعراض كافة المتدربين وإحصائياتهم (صلاحية Admin فقط).
* `GET /api/coaches/:id` - استرجاع الملف الرقمي الكامل المحدث للكوتش بجميع المهام والأدوات.

### 3. المهام والأدلة والتأمل (`/api/tasks`)
* `GET /api/tasks` - جلب قائمة مهام الكوتش الحالي.
* `GET /api/tasks/:id` - جلب تفاصيل المهمة واستمارة التأمل وسجل الأدلة.
* `PUT /api/tasks/:id/reflection` - حفظ وتحديث استمارة التأمل المهني الرباعية.
* `POST /api/tasks/:id/submit` - تسليم المهمة للجنة العلمية والمشرف للاعتماد.
* `POST /api/tasks/:id/evaluate` - رصد تقييم المشرف والملاحظات والتسجيل الصوتي (Admin فقط).

### 4. رفع الملفات الثبوتية (`/api/uploads`)
* `POST /api/uploads` - رفع دليل ثبوتي (Multipart FormData) وإرفاقه بالمهمة.

### 5. تطبيقات الأدوات الـ 90 (`/api/tools`)
* `GET /api/tools` - إحصائيات تطبيقات الأدوات وسجل المستفيدين.
* `POST /api/tools/apply` - تسجيل تطبيق أداة مع فحص منع التكرار.

### 6. تقييم الروبركات (`/api/rubrics`)
* `GET /api/rubrics` - استرجاع مصفوفة الروبركات الستة والدرجات الحالية.
* `POST /api/rubrics/evaluate` - تقييم المعايير واحتساب المتوسط وفحص الحظر الحاسم (Admin فقط).

### 7. البوابة الأخلاقية (`/api/ethics`)
* `GET /api/ethics` - حالة البوابة ونقاط التدقيق وسجل الإحالات.
* `POST /api/ethics/toggle` - تدقيق واعتماد نقاط الفحص الأخلاقي (Admin فقط).
* `POST /api/ethics/referrals` - تسجيل إحالة تخصصية جديدة.

### 8. التدقيق والاعتماد النهائي (`/api/audit`)
* `GET /api/audit/determination` - تدقيق الاستيفاء الشامل للشروط السبعة وفحص الحظر الأخلاقي.
* `POST /api/audit/determination` - إصدار قرار التخرج الرسمي والختم الرقمي (Admin فقط).

### 9. الإدارة المتقدمة (`/api/admin`)
* `POST /api/admin/reset-demo` - إعادة ضبط بيانات المنصة التوضيحية لقيم البدء الرسمية.
* `GET /api/admin/export` - تصدير نسخة احتياطية كاملة من قاعدة البيانات بصيغة JSON.

## 🛡️ نمط التشغيل المزدوج المبتكر (Resilient Dual-Mode Execution)
صُممت المنصة لتكون متينة وعالية الموثوقية:
* **عند التشغيل عبر الخادم (`npm start`):** تعمل المنصة بكامل طاقتها السحابية؛ حيث يتم التحقق من المستخدمين عبر الـ API وتخزين البيانات والملفات في SQLite و`uploads/`.
* **عند فتح `index.html` مباشرة دون خادم (Offline Standalone):** تكشف المنصة تلقائياً حالة عدم الاتصال وتعمل بسلاسة عبر `localStorage` مع الحفاظ على كافة المحركات التفاعلية، مما يتيح تشغيلها ومعاينتها في أي بيئة دون شروط مسبقة.
